空格听写
Mac 首次打开帮助

先确认下载自本项目官方 GitHub，再按顺序尝试。任一种成功后就停，正常打开无需运行命令。

方法一 · 在系统设置里允许打开

  1. 先尝试打开“空格听写”，然后打开“系统设置”。
  2. 点击“隐私与安全性”。
  3. 向下滚动到“安全性”，找到“仍要打开”。
  4. 点击“仍要打开”，如有密码或再次确认提示，按要求验证并点击“打开”。

方法二 · 一键复制终端命令

方法一仍未解决，且确认官方原包完整、仍因下载隔离标记受阻时，可尝试本方法。请先把应用放入“应用程序”。

  1. 点击上方按钮复制完整命令。
  2. 打开 Mac 的“终端”，粘贴后按回车。
  3. 如要求密码，输入 Mac 登录密码并回车。输入时不显示字符属正常现象。
  4. 返回“应用程序”，重新打开“空格听写”。无需固定运行两遍。
这个页面只复制命令，不会自动执行、读取密码或上传数据。命令只移除该应用的下载隔离标记，不能修复损坏或扫描病毒。提示“已损坏”时先重新下载官方原包；明确提示“将损坏你的电脑”时请停止打开。
