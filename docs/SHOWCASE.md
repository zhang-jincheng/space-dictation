# 空格听写 v1.3.0 · 展示与功能

## 新版主视觉

![空格听写主视觉](images/poster-hero.png)

大面积黄色、明快蓝色和清晰黑色描边，配合亮色、暗色、跟随系统三种外观。准备纸笔，按一次空格只听一个新词；按 R 重读当前词。

## 相比 v1.2.1 的新增功能

![新版功能](images/poster-features.png)

- 三种外观模式，随时切换并记住选择。
- 豆包／ChatGPT 两套提示词、两个独立复制按钮，共用相同提取和 CSV 导出规则。
- 素材可以是文字、文档、表格或图片；实际读取能力受 AI 平台支持限制，应用直接导入 TXT／CSV。
- 启动检查新版，弹窗列出变化。确认后后台下载、验证、自动安装并重新打开，不要求拖拽或点击安装向导。必要的操作系统授权仍须由用户完成。

完整变化见 [v1.3.0 发布说明](releases/v1.3.0.md)。

## 两个平台，相同的听写节奏

![跨平台版本](images/poster-platforms.png)

选词书 → 提前缓存标准录音 → 空格逐词听写 → 核对 → 错词重练。个人词表、四级、六级、雅思与本地备份继续保留。

Mac Apple Silicon 和 Windows x64 安装包从同一版本源码构建。安装后词表和练习记录保存在本机；录音缓存完成后可以离线练习。
