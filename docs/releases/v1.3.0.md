## 相比 v1.2.1，新版有哪些变化？

- 全新蓝黄界面：黄色面积更大，黑色描边更清楚，按钮和页面切换更有反馈。
- 新增亮色、暗色和跟随系统三种外观，可随时切换，并记住你的选择。
- 新增“复制豆包提示词”和“复制 ChatGPT 提示词”两个入口：提取、去重、释义、CSV 导出及保存规则完全一致。
- 提示词支持把文字、Word、PDF、Excel、图片／截图等素材交给 AI 整理；读不到的内容明确说明，不猜词。
- 新增启动更新检查：按本机系统与处理器匹配更新包，没有新版时不打扰。
- 确认更新后后台下载、签名验证、自动安装并重新打开；不再弹出 DMG 拖拽替换页面或安装向导。
- 更新弹窗展示新增功能和改进说明，下载与安装过程显示进度。

## 安装与升级

- Mac Apple 芯片：下载文件名含 `macOS-Apple-Silicon.dmg` 的安装包。
- Windows x64：下载文件名含 `Windows-x64-setup.exe` 的安装包。
- `.app.tar.gz`、`.sig` 和 `latest.json` 供应用自动更新使用，不需要手动打开。
- 已发布的 v1.2.1 尚不包含自动更新机制，首次升级需安装本版；安装 v1.3.0 后，后续更新可在应用内完成。
- 系统保护目录等特殊安装环境仍可能要求操作系统授权。当前未做 Apple 公证或 Windows 商业代码签名；更新包签名用于核验更新来源，不等同于系统代码签名。

## 保留原有功能

空格逐词听写、R 重读、标准录音提前缓存、个人词表及四级／六级／雅思、答案核对、错词重练与本地备份继续保留。录音缓存完成后可离线练习。

两套提示词不会自动发送素材，也不会假称普通 AI 客户端拥有本地写盘权限。AI 具体附件支持以平台实际能力为准；应用直接导入的是 TXT／CSV。
