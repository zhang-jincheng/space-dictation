## 相比 v1.3.2 的变化

- 精简设置页：移除应用内部重复的“Mac 首次打开”命令区域，保留外观、声音和备份设置。
- 首次打开帮助继续放在应用外：GitHub 安装说明与可下载的 `Mac-Install-Guide.html` 都能在应用无法启动时查看和复制命令。
- 更新安装文档和复制按钮测试；词表、练习记录及录音的保存方式不变。

## 下载与更新

- macOS Apple 芯片：下载 DMG，将应用放入“应用程序”。已安装 v1.3.0 及以上版本可在应用内更新。
- Windows x64：下载 `-setup.exe`；已有版本可在应用内更新。
- 安装帮助仅用于可信官方来源的首次打开拦截；正常打开时无需运行命令，不要用它绕过恶意软件警告。

更新包有更新签名校验；这不代表已经完成 Apple 正式公证或 Windows 发布者代码签名。
