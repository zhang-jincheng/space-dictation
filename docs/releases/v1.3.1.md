# v1.3.1 · 为缺少发音的词录制自己的声音

相比 v1.3.0：

- 缺少在线录音的单词或短语旁新增“开始录音”，核对页也提供“自己录音”入口。
- 使用本机麦克风录制，点击“停止并保存”即可保存在本机，支持试听与重录。
- 同一单词或短语跨词表复用个人录音，之后听写、重读及核对优先播放自己的声音，无需联网。切换英美音不会改变个人录音。
- 太短、没有声音或录音中断时提示重试；失败的重录保留原先有效的录音。
- 每次最长 60 秒，关闭窗口或切换到其他窗口会取消未保存的录音。首次录音需要允许系统的麦克风访问。

个人录音保存在应用数据目录的 `personal-recordings-v1/`，不会上传。现有 JSON 备份不包含音频，迁移到其他电脑需同时复制这个文件夹。
