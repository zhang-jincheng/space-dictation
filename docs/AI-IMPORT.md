# 用豆包或 ChatGPT 收词

“我的词表”提供“复制豆包提示词”和“复制 ChatGPT 提示词”两个按钮。点击对应按钮后，将提示词粘贴给 AI，再提供素材和要提取的单词范围。界面会预览刚复制的完整提示词。

两套提示词使用完全相同的提取、去重、释义、CSV 编码与保存规则，只有开头的助手称呼不同。素材可来自文字、DOCX、PDF、Excel、图片或截图等；实际读取能力受所用 AI 的版本和附件支持限制，看不清的内容必须说明，不编造。

输出固定为 UTF-8 的 `word,translation` 两列 CSV，保留拼写与短语空格，忽略大小写并按首次出现顺序去重，不确定释义留空。

有本机写入工具时可保存到提示词里的真实收件箱目录，不能覆盖已有文件。普通网页／客户端未获本机文件权限时，应生成可下载的 CSV 附件；下载到收件箱后，在应用点击“刷新收件箱”和“预览导入”。无法生成附件时，可在应用新建词表、选 CSV 格式并粘贴完整内容。

应用本身目前直接导入 TXT／CSV，并不直接读取 Word、PDF 或图片。两个复制按钮不会发送素材、不会自动启动 AI，也不要求用户必须安装某一款 AI 客户端。
